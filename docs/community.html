Community

What Viboplr listeners share with each other. It all lives on community.viboplr.com; here's what's there right now.

Share your own

Browsing and using what others shared needs no account, except Subsonic servers, which only signed-in members see. To share, sign in with GitHub on community.viboplr.com — no password to create.

1

Sign in

With GitHub, on the website or from the Viboplr Community plugin in the app. You manage only what you share.

2

Share

Some things are shared from the website (like servers), some from the app where you made them (like cue sheets). Each section above says how.

3

Keep it tidy

Edit or unpublish anything you've shared from your account. Spot a problem in someone else's? Report it there.
