  • macOS

    Download for macOS

  • Windows

    Windows 10 or 11, 64-bit. An .exe installer.

    Download for Windows

The app checks for new versions and tells you when one is ready. It installs only when you click.

Beta:

Built between stable releases and less tested. With Settings → Beta updates on, a beta keeps itself updated and moves back to stable when a newer stable ships.

Requirements

macOS11 (Big Sur) or later, Apple Silicon. Intel Macs are not supported.
Windows10 or 11, 64-bit. Uses Microsoft Edge WebView2, which Windows 11 already has; on Windows 10 the installer adds it if missing.
DownloadAbout 30 MB
Disk200 MB, plus room for the artwork cache
MemoryAbout 200–300 MB while running
InternetNot needed to play your own files. Updates, plugins and artwork use it.
