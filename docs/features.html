Features

Everything Vibo does, as a list. Items marked plugin need a plugin from the gallery.

Library and sources

  • Local folders, scanned in the background and watched for changes.
  • Subsonic and Navidrome servers, in the same library and queue as your folders.
  • Tags are read from the files. An album belongs to its album artist, so a compilation stays one album.
  • Full-text search over artists, albums, tracks and tags. Accents and case are ignored.
  • Tracks, albums, artists and tags views, each with its own detail page.
  • Play history you can search and sort.
  • Like or dislike tracks, artists, albums and tags. Export your likes to a file and import them on another computer.
  • Separate profiles, each with its own library and settings.
  • Spotify browsing and YouTube playback.plugin

Playback

  • Audio and video through libmpv, with the files played as they are.
  • Gapless playback, and crossfade from 0 to 10 seconds.
  • Bit-perfect mode and exclusive output for external DACs.
  • ReplayGain, a 10-band equalizer and clip protection.
  • A queue you can reorder, trim and save as an .m3u8 playlist.
  • Playlists, and mixtapes: a playlist exported together with its files.
  • A mini player in three layouts that can stay on top of other windows.
  • A full-window theater for video.
  • Keyboard shortcuts for playback, volume, navigation and search, with an overlay that lists them.

Listening

  • A home screen with radio stations from your library and shelves: your latest play, mixes made for you, lists of recent additions and most played, albums by decade and forgotten favorites.
  • Radio from any song, artist or tag, built from your library. You choose how much of the seed artist it plays, whether it leans to favorites or to songs you rarely play, and how many songs per artist.
  • Auto-continue adds more music when the queue ends.
  • Synced lyrics from .lrc files; click a line to jump to it.
  • Online lyrics, bios, similar artists and cover art.plugin
  • Cue sheets: notes and pictures timed to a song, shown on Now Playing.
  • Scrobbling to the local history and to plugins such as Last.fm, with an audio and a video switch for each.plugin

Editing and downloads

  • Edit artist, album artist, album, year and tags for many tracks at once, written into the files.
  • Fix the title, artist or album of a queue entry without touching the file.
  • Download the playing track from where it is playing: your server, a web address, or the plugin that provides it.
  • Replace a local file with a better copy after comparing the two; likes, tags and playlists stay with it.plugin
  • Deleted tracks go to the trash.

AI control and the control API

  • One setting, Settings → AI control: Off (the default), Low, Full or Custom.
  • A server on 127.0.0.1 only, with an access token you can regenerate.
  • A bundled MCP server for Claude Desktop, Claude Code or any MCP client. Settings copies the config.
  • The same server is a plain HTTP API, with a Claude Code skill that documents it.
  • Separate permission switches for writing tags to files, managing files, downloading, plugin actions, deleting, and clicking in the window.
  • File moves and deletions are returned as a plan first and applied only when the plan is sent back.
  • Installed plugins can add their own tools for the assistant.

Plugins and skins

  • Plugins are a manifest.json and an index.js in plain JavaScript, with no build step. See writing a plugin.
  • A plugin can add music sources, sections on detail pages, home shelves, sidebar views, context-menu items, scrobblers, download providers and AI tools.
  • Each plugin declares its permissions, and the app shows them before installing.
  • Install and update plugins from the in-app gallery. Updates come from each plugin's GitHub releases.
  • Eight built-in skins, light and dark, plus a skin gallery. A skin is 19 colors and optional CSS, made in the in-app editor.

How it is built

  • Rust and Tauri 2 for the backend, React and TypeScript for the interface, SQLite for the library, libmpv for playback.
  • The system's own webview (WebKit on macOS, WebView2 on Windows), so no browser engine is bundled. The download is about 30 MB.
  • Searching a 20,000-track test library takes under 40 ms (cargo test bench_search_performance -- --ignored).
  • The app checks for updates and installs one when you click.
  • No account. Anonymous usage stats, with a switch to turn them off.
  • Open source under the GPL-3.0 license, on GitHub.
