Jaangle

Before Vibo there was TeenSpirit, later renamed Jaangle: a music player and library organizer for Windows, written by hand in C++ between 2003 and 2010. Many of Vibo's ideas come from it.

It still runs, and it is still fast. In 2026 its last version (0.98f-rc1) was updated so it builds with current tools, in 32-bit and 64-bit.

Source on GitHub

What it did

  • A music library organized by artist, album, genre, year and date added, with fast search, including accented and non-Latin names.
  • Playback through BASS (MP3, OGG, FLAC, WMA, AAC/M4A, APE, WavPack, MPC, AC3, MIDI, audio CD) with crossfading and an equalizer. Video through DirectShow.
  • Tag reading and editing with TagLib, ratings, play history and statistics.
  • Album covers, artist pictures, lyrics and biographies downloaded automatically, plus pictures found in the music folders, and comments and notes per track.
  • Last.fm scrobbling, a mini player, skins, global hotkeys, a music quiz and 17 translations.

How it was built

  • C++ with MFC on the Win32 API, about 600 source files.
  • The library lived in a Microsoft Jet database (music.mdb). The 2026 update moved it to SQLite.
  • Online information came through one provider interface, with providers for the cache, for pictures in the music folder and for online services, and a composite provider that tried them in order.
  • The development notes from 2005–2006, written in Greek, are in the repository's Documents folder.

What is different

  • Jaangle runs on Windows only. Vibo runs on macOS and Windows.
  • Jaangle had its online services built in, and most of them have since shut down. In Vibo they are plugins, so one can be replaced without a new release of the app.
  • Jaangle was written by hand. Vibo was written by an AI coding assistant. See how it was made.

Running it today

There is no download; it is built from source. You need Visual Studio 2026 with C++, ATL/MFC, the Windows SDK and vcpkg. Run tools\fetch-bass.ps1 once, then build Jaangle.sln. The steps are in BUILDING.md, and an x64 MSI installer can be built from the same source.
