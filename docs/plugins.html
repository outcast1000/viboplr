Plugins

Anything in Vibo that talks to an outside service is a plugin. Install them inside the app from Extensions in the sidebar; this is the same list. Each plugin shows the permissions it asks for before it installs.

Recommended

All plugins

Experimental

These may break, change or be removed without notice.

Write a plugin

  1. Write a manifest.json (what the plugin adds) and an index.js (plain JavaScript, using the plugin API). There is no build step.
  2. Point Settings → Developer → Dev plugin folder at your folder, then edit and press Reload. See developing locally.
  3. Publish a GitHub release with a zip and an update.json. Installed copies update from your releases.

Details: plugin developer docs.

Add it to the gallery

  1. Open the submission form and paste your release's update.json URL.
  2. A bot downloads the zip, checks the manifest, and either comments what to fix or opens a pull request.
  3. A maintainer reviews and merges it.

More in the submission guide.
