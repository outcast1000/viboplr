Skins

A skin sets the app's colors, and can add custom CSS. Install them inside the app from Extensions → Skins; this is the same list.

Make a skin

  1. In the app, open Extensions → Skins → New skin and adjust the colors. Or write the JSON by hand with all 19 color keys.
  2. Press Submit to gallery, or paste the JSON into the submission form.
  3. A bot checks the colors and any customCSS, then opens a pull request for a maintainer to merge.

More in the submission guide.
