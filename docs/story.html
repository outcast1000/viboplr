How it was made

Before Vibo I wrote Jaangle, an open-source music player for Windows, in C++, by hand. It taught me what a player should do, and how long each feature takes when one person writes every line.

Vibo was built differently. An AI coding assistant wrote the code. I decided what to build, described how it should behave, reviewed the changes, tested them, and sent them back until they were right.

That is how one person could build a player with this many parts: gapless playback, synced lyrics, radio, mixtapes, skins and a plugin system. The whole history is public in the commit log.

The name is said like vibe with an “o” at the end: VYE-boh.
