Support the project

Vibo is free and open source. If you want to help pay for its development:

GitHub Sponsors Ko-fi

Thank you. There is a small game in the app for you: a quiz that plays a few seconds of a random track from your library and asks you to name it. With Vibo running, open the Song Quiz.

Other ways to help

  • Report a bug or ask for a feature. In the app, Settings → Debug → Problems builds a report you can paste.
  • Write a plugin or make a skin.
  • Star the repository, or tell someone who might use it.
